      Thiết kế bài dạng

      1. Nạp dữ liệu từ file
      Kéo thả file hoặc cả thư mục vào đây
      Word, PowerPoint, PDF, ảnh, .zip: tự nhận file nào là slide, giáo án hay phiếu bài tập. Nạp thêm lần nữa thì nội dung được cộng vào.
      Ví dụ: file thế nào thì lên web thế nào

      Có thể dán thẳng bảng từ Word hoặc Excel vào từng ô bên dưới, các cột sẽ tự tách bằng dấu |.

      2. Mẫu giao diện

      Bốn mẫu đầu đổi cả bố cục (cách xếp thẻ từ, mục lục, hội thoại…); ba mẫu sau giữ bố cục chuẩn, chỉ đổi màu và kiểu chữ. Bấm để xem ngay ở khung bên phải.

      3. Thông tin bài
      Ảnh bìa
      Bài giảng trong giáo trình

      4. Mục tiêu và tiến trình

      Mỗi dòng một ý. Viết **chữ** để in đậm.

      9. Ảnh
